# Sasta Finder

Sasta Finder is a frontend price comparison platform prototype. It lets users search, filter, sort, and compare product prices across simulated e-commerce platforms in a responsive single-page interface.

## Features

- Product search by name, brand, and tags
- Search suggestions while typing
- Category, platform, and price range filters
- Sorting by best price, savings, rating, popularity, and newest items
- Grid and list product views
- Product detail modal with price comparison table
- Toast notifications for user feedback
- Light and dark theme support with saved preference

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage for theme preference
