Sasta Finder - Advanced Price Comparison Platform
Sasta Finder is a sophisticated front-end project that simulates a real-time price comparison website. It allows users to search, filter, and compare prices for various products across multiple e-commerce platforms, helping them find the best deals instantly. The project is built with modern web technologies and focuses on a clean, responsive, and interactive user experience.

✨ Features
This project is packed with features that mimic a full-fledged price comparison service:

🎨 Dual Theming: Seamlessly switch between a light and a dark mode. Your preference is saved in localStorage for a consistent experience on your next visit.

🔍 Advanced Real-time Search:

Instantly search for products by name, brand, or descriptive tags.

Receive intelligent search suggestions as you type.

📊 Dynamic Filtering & Sorting:

Category Filters: Quickly filter products by categories like "Groceries," "Electronics," and "Fashion."

Price Range Slider: Use a dual-handle slider to define a custom price range.

Platform Filters: Select specific e-commerce platforms to include in your search.

Advanced Sorting: Sort the results by Best Price, Highest Savings, Most Popular (by reviews), Highest Rated, or Newest.

📱 Fully Responsive Design: The interface is beautifully crafted to provide a seamless experience on desktops, tablets, and mobile devices.

🧩 Interactive UI Components:

Product Modal: Click on any product to open a detailed modal with a comprehensive price comparison table across all available platforms.

Toast Notifications: Receive non-intrusive feedback for actions like applying filters or making a purchase.

Toggleable Views: Switch between a modern Grid View and a detailed List View for product listings.

Collapsible Filter Panel: An advanced filter section that neatly slides down when needed.

🚀 Modern & Animated UI: The project uses pure CSS for smooth animations, floating background shapes, and subtle transitions, creating a premium user experience.

🛠️ Tech Stack
The project is built entirely with front-end technologies, with a focus on clean, vanilla code without any external libraries or frameworks for the core logic.

HTML5: Semantic markup for a well-structured and accessible layout.

CSS3:

CSS Variables: For easy theming (light/dark modes) and maintainable styling.

Flexbox & Grid: For building complex, responsive layouts.

Animations & Transitions: For a fluid and engaging user interface.

Vanilla JavaScript (ES6+):

DOM Manipulation: To dynamically render products, modals, and other UI components.

State Management: A central appState object to manage filters, sorting, and UI state.

Event Handling: To create a fully interactive and responsive user experience.

📂 Project Structure
The project is organized into three main files:

sasta-finder/
├── index.html       # The main HTML file with the page structure
├── style.css        # The stylesheet for all visual aspects
└── script.js        # The JavaScript file for all application logic
index.html: Contains the complete HTML structure of the single-page application, including the header, hero section, product dashboard, modal, and footer.

style.css: A comprehensive stylesheet that handles all visual aspects, including the layout, theming, responsiveness, and animations.

script.js: The heart of the application. It manages the product data, application state, and all user interactions, from searching and filtering to rendering dynamic content.

🚀 Getting Started
To run this project locally, simply follow these steps:

Download the repository or save the three files (index.html, style.css, script.js) in the same folder.

Open the index.html file in your favorite web browser (e.g., Chrome, Firefox, Edge).

That's it! The project is now running locally.
